# Code of Conduct

This project follows the **Contributor Covenant, version 3.0**
(<https://www.contributor-covenant.org/version/3/0/code_of_conduct/>),
released 2025-07-28 - the current major version.

## Our standards

We are a small group project. The short version of 3.0 applies here:

- Be kind, be honest, be direct. Critique work, not people.
- Respect that this is a creative space - feedback is generous, scope is honest.
- Assume good faith; verify before escalating.

## Enforcement

Project decisions and conduct issues go to the two owners:

- **Christian** - product owner
- **Rich** - engineering lead

Report privately to either owner. Incidents are handled per Contributor
Covenant 3.0's "Addressing and Repairing Harm" process - proportional,
restorative, and documented in the decision register where a project-level
consequence results.

The full 3.0 text is incorporated by reference at the URL above; if this
project goes public with outside contributors, we will adopt the full text
inline at that time.
